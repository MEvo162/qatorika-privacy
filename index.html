Qatorika Privacy Policy

Effective date: September 17, 2026

Qatorika is a local-first browser testing extension. It processes data inside the user's browser to provide tools the user explicitly starts. Qatorika has no remote backend, analytics, advertising, or user accounts.

Data processed

Depending on the selected tool, Qatorika may temporarily process the current page URL and title, selected text and element metadata, page structure and styles, form fields, cookies and web storage, network request and response details, console errors, screenshots, test-session events, browser environment information, and text entered by the user.

This information is used only to provide the requested testing function. Qatorika does not sell data, use data for advertising, build user profiles, or transfer data to third parties.

Storage and retention

Most captured page, network, console, screenshot, and session data is kept in memory and discarded when the relevant Qatorika page or browser session ends. Language preference, saved environments, and mock scenarios may be stored locally in browser extension storage until the user removes them or uninstalls the extension. Files are copied or downloaded only after an explicit user action.

Permissions

  • activeTab and scripting: temporary page access after the user invokes Qatorika.
  • contextMenus: the nested right-click launcher.
  • debugger: user-started network capture, request replay, console diagnostics and response mocking.
  • cookies: the user-selected State Manager.
  • storage: local preferences, environments and mock scenarios.
  • tabs: selected-tab identification and user-requested pages or viewport tools.

Qatorika does not request persistent host permissions and does not automatically run on every website.

User control

Users can stop recording tools, clear captured information, remove locally saved items, or uninstall Qatorika to remove extension storage. Browser-managed downloads remain under the user's control.

Security and authorized use

Qatorika is intended for testing systems that the user owns or is authorized to test. Sensitive captured data should be handled according to the policies of the tested system.

Changes

Material changes will be reflected by updating this page and its effective date.
