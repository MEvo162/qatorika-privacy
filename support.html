Qatorika Support

Qatorika is a local-first browser QA toolkit. If you have a question, found a bug, or need help using a feature, contact us at qatorika@yandex.com.

Before contacting support

  • Reload Qatorika on chrome://extensions after installing an update.
  • Refresh the webpage you want to test.
  • Remember that browser-internal pages and extension-store pages cannot be inspected.
  • Stop Network Inspector, request replay, or mocking when you finish testing.

What to include in a bug report

  • Qatorika version and browser version.
  • Steps required to reproduce the problem.
  • Expected and actual results.
  • A screenshot, if it does not contain confidential information.

Response

Support requests are reviewed by the Qatorika publisher. Please do not send passwords, authentication tokens, private cookies, or other sensitive test data.
